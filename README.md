# Karabiner-Elements Keybinds

A place to track, backup, share the config that I use when docking my Mac to a Windows keyboard. 

Give MacOS that Windows feel but without any of the AI nonsense. 

Keyboard shortcuts should be able to be OS agnostic. 

Perhaps in the future an AutoHotkey script could be added to make windows behave like MacOs when it has a Mac keyboard plugged in, but I designate that permenatnly out of scope.

## Current Rebinds

| Windows Keys | Mac Keys | Functionality Description |
|---|---|---|
| Alt+Tab | Command+Tab | Switch window |
| Control+A | Command+A | Select all |
| Control+Command+Left | Control+Left | Switch desktop left |
| Control+Command+Right | Control+Right | Switch desktop right |
| Command+Period | Control+Command+Space | Open emoji picker |
| Control+Left | Option+Left | Jump one word left |
| Control+Right | Option+Right | Jump one word right |
| Control+Backspace | Option+Delete | Delete one word backward |
| Control+Delete | Option+Forward Delete | Delete one word forward |
| Command+Shift+S | Command+Shift+5 | Open screenshot toolbar |
| Control+Enter | Command+Enter | Submit/send in supported apps |
| Control+B | Command+B | Bold |
| Control+I | Command+I | Italic |
| Control+U | Command+U | Underline |
| Control+W | Command+W | Close tab/window (except VS Code variants) |
| Control+T | Command+T | New tab/window (except VS Code variants) |
| Control+N | Command+N | New browser window (browser apps only) |
| Control+Shift+W | Command+Shift+W | Open last closed tab/window |
| Command+Tab | Control+Up | Open Mission Control |
| Control+C | Command+C | Copy (external keyboards only) |
| Control+X | Command+X | Cut |
| Control+V | Command+V | Paste |
| Control+F | Command+F | Find |
| Control+Z | Command+Z | Undo |
| Control+S | Command+S | Save |
| Control+Plus | Command+Plus | Zoom in |
| Control+Minus | Command+Minus | Zoom out |
| F5 | Command+R | Refresh page |
| Numpad 3 | Brightness Down | Decrease display brightness |
| Numpad 6 | Brightness Up | Increase display brightness |
| Caps Lock | Escape | Send Escape when pressing Caps Lock |
| F5 (fn_function_keys) | None (vk_none) | Disable raw F5 function-key output at fn layer |
